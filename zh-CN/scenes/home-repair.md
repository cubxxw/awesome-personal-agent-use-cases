# 维修档案 · 坏了先找上次修过的人

[首页](../../README.zh-CN.md) · [English](../../scenes/home-repair.md)

**一个 Muse 替你存的家庭维修档案：管每台设备的型号、上次谁修的、花了多少、保修到哪天。东西坏了，先把上次的师傅和工单找出来给你，不用从头打听。**

## 你能得到什么

- **一台设备一页档案**——型号规格、购买时间、保修期限、历次维修：日期、服务商、联系方式、修了什么、花了多少、工单和收据在哪。
- **坏了先查档案**——报出设备名，Muse 先给上次的服务商和工单；联系方式是当时的，它会提醒你先核对再联系。
- **没有记录时的一套询价材料**——型号、规格、故障照片收齐，生成一份询价草稿，你确认了才发给商家。

## 把这段交给 Muse

整段复制给你的 Muse，它照着把档案建出来，然后陪你跑起来。

```text
帮我建一个家庭维修档案，名字叫「维修档案」。

一台设备一页：型号和规格、购买时间、保修到哪天；下面是历次维修记录——日期、服务商、联系方式、修了什么、金额，工单和收据的原件位置。

进料：先在我指定的邮箱或文件夹里找旧工单、收据和维修记录，按设备归档；对不上任何设备的，进待确认，不要猜着挂。

规则：
1. 我说某台设备坏了，先查档案：给我上次的服务商、工单和当时的联系方式，并提醒我联系方式可能已变、先核对。
2. 档案里没有这台设备时，帮我收齐询价要用的材料——型号、规格、故障描述和照片——起草一份询价，我确认了才发。
3. 收到的报价和约好的上门时间分开记：报价是报价，约成是约成。
4. 每次维修办完，把新工单回填到那台设备的档案里。

现在就开始：先把档案建起来，然后问我先从哪个邮箱或文件夹找旧工单。
```

## 它怎么运转

- **档案随维修长大**——每修一次，档案厚一页；下次同台设备出问题，起点就是上次的工单。
- **找人靠记录，不靠记忆**——师傅电话、保修期限这种事，不再靠你想「上次好像是找谁修的」。
