# 晨间行动单 · 开工前看真要办的几件事

[首页](../../README.zh-CN.md) · [English](../../scenes/daily-plan.md)

**一份 Muse 每天早上替你排好的行动单：从日历、到期事项和待回复里，挑出今天真要办的几件事——一条主线、最多三件，每件写清开始时间、下一步和卡在哪。等别人的事单独放进等待区。晚上用同一张单子收尾：办完、顺延，还是放下。**

## 你能得到什么

- **一张晨间行动单**——一条主线（今天最重要的一件事）加最多三件要办的事，有硬时间的先排，剩下的按到期先后。没有日期的事不占今天的位置。
- **一个等待区**——卡在别人那里的事（等回复、等交付）单独列着，不占你的注意力，但也不会丢。
- **一次晚间收尾**——晚上回到同一张单子，每件标：办完、顺延到哪天、还是放下。昨天的事不无声无息地滚进今天。

## 把这段交给 Muse

整段复制给你的 Muse，它照着把行动单建出来，然后陪你跑起来。

```text
帮我建一份每日行动单，早上生成，晚上收尾。

材料：我指定的日历、待办来源和待回复清单。只用能读到的材料；哪个来源读不到，在单子上标明缺了什么，不要假装看过。

早上（按我定的时间）：
1. 先定主线：从今天的安排里挑一件最重要的事，单独置顶。
2. 再排最多三件今天真要办的：有硬时间的写开始时间；到期的写截止；每件写清下一步是什么、卡在哪。
3. 等别人的事放进「等待区」，写清在等谁、等什么。
4. 没有日期、今天不用碰的事，不要放进来。

晚上（按我定的时间）：
5. 回到同一张单子，逐件问我：办完、顺延（顺到哪天）、还是放下。
6. 顺延的进明天的候选，放下的就此关闭，不要第二天又原样端出来问我。

现在就开始：先问我接哪个日历和待办、早上几点送、晚上几点收尾，再拿今天跑第一张给我看。
```

## 它怎么运转

- **早晚同一张单子**——早上排的是它，晚上结的也是它；一天有没有推进，看晚上的收尾就知道。
- **来源坏了要出声**——日历读不到和今天没安排，是两件完全不同的事，单子上分得清清楚楚。
