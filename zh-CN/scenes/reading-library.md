# 收藏库 · 找回曾经收藏的那一篇

[首页](../../README.zh-CN.md) · [English](../../scenes/reading-library.md)

**一个 Muse 替你管收藏的库：文章、视频、帖子，存的时候连「为什么存」一起记下来，按原始来源去重。以后你用大白话问「我存过一篇讲 X 的」，它把原文和你当时的笔记一起找回来——收藏的意义不是存下来，是找得到。**

## 你能得到什么

- **一条带理由的收藏记录**——原文链接、你存它时的一句话（为什么存、打算用在哪）、存的时间、读没读。没有理由的收藏，三个月后等于没存。
- **用问的找回**——不用记标题、不用翻收藏夹：描述一下内容或用途，它按你的笔记和原文一起找，给你最对得上的那几条。
- **同源只存一份**——同一篇文章从群里、邮件里各存一次，合并成一条，你的几句笔记都保留，不丢任何一句。

## 把这段交给 Muse

整段复制给你的 Muse，它照着把收藏库建出来，然后陪你跑起来。

```text
帮我建一个收藏库，管我存下来的文章、视频和帖子。

我给你一个链接或一份材料时，这样登记：原始来源、标题、我为什么存（我没说就问我一句，不要替我编）、存的时间、读没读。

规则：
1. 按原始来源去重：同一来源再存一次，把我的新笔记补进已有记录，不要建第二条。
2. 只看到标题、还没读的，标「未读」；不要从标题猜正文写进记录。
3. 我问「我存过一篇讲 X 的」时，按我的笔记和原文内容一起找，给最对得上的几条，每条带我当时写的那句话和原文链接。
4. 原件留在原来的地方，库里只存记录和链接；我要删哪条，我说了才删。

现在就开始：先把库建起来，然后问我先导入哪批收藏——浏览器收藏、某个 App 的收藏夹，还是我现在发你的几条。
```

## 它怎么运转

- **进料越随手越好**——聊天里发个链接、截图里带个标题，都能登记；门槛低，库才长得起来。
- **笔记是检索的钥匙**——你当时写的那句「为什么存」，就是日后找回它的路标；所以它每次都会问你那一句。
