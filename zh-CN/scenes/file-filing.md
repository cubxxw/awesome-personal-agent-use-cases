# 文件档案柜 · 三个月后找得到那张发票

[首页](../../README.zh-CN.md) · [English](../../scenes/file-filing.md)

**一个 Muse 替你归档文件的档案柜：管发票、收据、保修单、合同这类「以后还要找」的文件——原件先不动，它建一份能搜的索引：哪个商户、哪天、多少钱、原件在哪。三个月后要报销、要保修，一句话找回来。**

## 你能得到什么

- **一份能搜的索引**——每个文件一行：文件名、商户、日期、金额、类别、原件位置。找的时候按商户、金额、月份问就行。
- **先预览、后归档**——它先给你一张去向清单：哪个文件建议放哪个目录。你确认了，才复制归档；原件永远保留。
- **重复报警**——同一张发票从两个邮箱各来一份（票号、金额都一样），标「疑似重复」，先对文件再决定删不删，绝不自动合并。

## 把这段交给 Muse

整段复制给你的 Muse，它照着把档案柜建出来，然后陪你跑起来。

```text
帮我建一个文件档案柜，先建索引，不动原件。

范围：我指定的邮箱或文件夹，只读。先找发票、收据、保修单、合同这类以后还要用的文件。

索引每行记：文件名、商户、日期、金额、类别、来源（哪封邮件、哪个文件夹）、原件位置。字段看不清的标「待核对」，不要猜。

规则：
1. 疑似重复——票号相同，或商户+日期+金额都相同——单独标出来给我对，不要自动合并、不要删任何一份。
2. 归档先给预览：每个文件建议去哪个目录，我确认整张清单后，你才复制过去；原件留在原地，索引里记新位置。
3. 移动和删除分开授权：确认了归档，不等于可以删原件。

现在就开始：先问我从哪个邮箱或文件夹开始，先给我一份索引预览。
```

## 它怎么运转

- **索引先行，整理随后**——文件夹再乱，先有索引就能找；目录整理是第二步，不阻塞使用。
- **新文件自己入柜**——新收据、新保修单进来，顺手登记一行，档案柜不会过期。
