# 国内工具接入

如果在中国大陆，可接入高德地图、坚果云、Bark等服务。

**完整路径** (6条):
1. [高德地图](china-tools/01-amap.md) - POI查询、路线、导航链接
2. [坚果云WebDAV](china-tools/02-jianguoyun.md) - 文件跨设备存储
3. [Bark通知](china-tools/03-bark.md) - 异步结果推送iPhone
4. [飞书文档](china-tools/04-feishu.md) - 读写云文档(区分远程/本地MCP)
5. [原生RSS](china-tools/05-rss.md) - RSS订阅、RSSHub限制
6. [邮件IMAP](china-tools/06-imap.md) - QQ/163邮箱读取

**可选进阶**:
- [手机文件分享](china-tools/phone-share.md) - 需要自建HTTPS endpoint
- [Home Assistant](china-tools/home-assistant.md) - 设备控制

不改变现有19场景数量，作为国内替代实现。
