## 使用说明

### 选择工具

**优先推荐** (配置明确):
- 高德地图: 地理位置相关任务
- 坚果云: 需要文件持久化
- Bark: 需要手机通知
- 原生RSS: 订阅公开信息源
- IMAP: 需要读取邮箱

**暂缓使用**:
- 飞书: 等待明确配置文档
- 手机分享: 需要自己搭建服务器

### 检查清单

每条工具使用前检查:
- [ ] 前置条件是否满足
- [ ] 账号是否已注册
- [ ] Key/密码是否已获取
- [ ] Host配置方法是否明确
- [ ] 测试步骤是否可执行

### 测试顺序

建议测试顺序:
1. 高德(如有桌面MCP Host)
2. Python示例(坚果云/RSS/IMAP)
3. Bark(如有iOS设备)

## 重要说明

### 不是开箱即用

所有工具都需要:
- 注册账号
- 获取凭证(Key/密码/Token)
- 配置Host或编写代码
- 理解限制和风险

### Muse适配未确认

本指南使用Claude Desktop等作为参考Host，Muse适配情况需自行验证。

### 保持更新

官方API可能变更，使用前查看:
- 官方文档最新版本
- API是否仍然可用
- 配额和限制是否变化
