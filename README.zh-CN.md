# 个人 Agent 用例库

把需要反复记、反复查、反复做的事交给个人 Agent。每个玩法先给你看结果，打开就有一段带样例的提示词可以试。

[English](README.md) · [架构与收录思路](ARCHITECTURE.md) · [贡献方式](CONTRIBUTING.md)

**先试 [做一个会持续更新的个人 CRM](zh-CN/usecases/personal-crm.md)**

朋友在聊天里说自己搬家了。把更新记到同一张联系人卡，保留消息出处。下次见面前，可以直接问 Agent 最近聊过什么、还有什么事要跟进。

## 主动跟进

| 玩法 | 你会拿到什么 |
| --- | --- |
| [定时任务 · 到点给我一份行动单](zh-CN/usecases/scheduled-task.md) | 在你指定的时间看到需要处理的事。 |
| [变化监控 · 有变化再叫我](zh-CN/usecases/change-watch.md) | 关注的状态真的变了，才收到一条有根据的通知。 |

## 长期维护

| 玩法 | 你会拿到什么 |
| --- | --- |
| [个人 CRM · 联系人卡跟着聊天更新](zh-CN/usecases/personal-crm.md) | 每个人有一张能更新、能查出处、会前用得上的卡。 |
| [到期台账 · 哪些事快到期了](zh-CN/usecases/renewal-ledger.md) | 账单、会员、退货等近期需要决定的事，在一起看。 |
