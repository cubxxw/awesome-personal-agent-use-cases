# Repair records · Find who fixed it last time

[Home](../README.md) · [简体中文](../zh-CN/scenes/home-repair.md)

**Repair records Muse keeps for your home: each appliance's model, who fixed it last time, what it cost, and when the warranty ends. When something breaks, the last technician and work order are in front of you — no starting from scratch.**

## What you get

- **One record per appliance** — model and specs, purchase date, warranty end, and every repair: date, provider, contact, what was fixed, what it cost, and where the work order and receipt live.
- **Breakdowns start from the record** — name the appliance and Muse hands you the last provider and work order. The contact is from back then, and it will tell you to verify it before you call.
- **A quote pack when there is no record** — model, specs and fault photos gathered into one inquiry draft. It goes out only after you approve it.

## Give this to Muse

Paste the whole block into your Muse. It builds the records, then runs them with you.

```text
Build me home repair records called "Repair records".

One page per appliance: model and specs, purchase date, warranty end. Below that, every repair — date, provider, contact, what was fixed, amount, and where the work order and receipt originals are.

Intake: search the inbox or folder I name for old work orders, receipts and repair records, and file them by appliance. Anything that matches no appliance goes to a review list — never guess which machine it belongs to.

Rules:
1. When I say an appliance broke, check its record first: give me the last provider, the work order, and the contact from that time — and remind me the contact may have changed, so verify before relying on it.
2. When there is no record for it, gather what a quote needs — model, specs, fault description, photos — and draft one inquiry. Send it only after I approve.
3. Keep quotes and booked visits separate: a quote is a quote; a confirmed appointment is a different fact.
4. After each repair, file the new work order back onto that appliance's page.

Start now: set up the records, then ask me which inbox or folder to search for old work orders first.
```

## How it runs

- **The record grows with every repair** — each fix adds a page of history, so the next problem with the same machine starts from the last work order.
- **Finding people runs on records, not memory** — a technician's number and a warranty date stop depending on you remembering who fixed it last time.
