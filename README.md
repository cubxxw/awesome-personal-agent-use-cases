# Awesome Personal Agent Use Cases

Start with something you need to do. Each scenario shows a result, gives you a sample to try, and explains how to check it.

[简体中文](README.zh-CN.md) · [Builder guide](BUILDER.md) · [Sources and selection](EVIDENCE.md) · [Design](ARCHITECTURE.md) · [Contribute](CONTRIBUTING.md)

**Start with [What will I pay for next?](scenes/renewal-ledger.md)** Try making a renewal list from sample receipts and notices.

## Life

| Scenario | What you get |
| --- | --- |
| [Family and routines · Who needs to be where this week?](scenes/household-calendar.md) | A shared week view with confirmed events, clashes and pickups still to arrange. |
| [Bills and subscriptions · Tell me before I’m charged again](scenes/renewal-ledger.md) | A renewal shortlist with the next date, billing channel and notice for each decision. |
| [Friends and contacts · Remember where we left off](scenes/personal-crm.md) | One contact card with the latest confirmed details, last conversation and open follow-ups. |
| [Home and repairs · Find who fixed it last time](scenes/home-repair.md) | The right work order, a contact lead to verify and any missing details for a new quote. |
| [Travel · Put all the bookings on one page](scenes/trip-brief.md) | A trip sheet with local times, confirmation sources and the gaps to check before leaving. |
| [Shopping and tickets · Tell me when it fits my budget](scenes/price-watch.md) | A timestamped alert for a comparable offer, with the full price and a link to inspect. |

## Work

| Scenario | What you get |
| --- | --- |
| [Email and messages · Which ones need my reply today?](scenes/inbox-triage.md) | A short inbox list with urgent replies, items to review later and messages that need no action. |
| [Documents and records · Find that invoice months later](scenes/file-filing.md) | A searchable file index with source, suggested folder and duplicates to review. |
| [Before a meeting · Walk in with the context](scenes/meeting-prep.md) | A one-page brief with the last decision, what is unresolved and the question to ask next. |
| [After a meeting · Who agreed to do what?](scenes/meeting-followups.md) | A reviewable list of decisions, confirmed work and questions still missing an owner. |
